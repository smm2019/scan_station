# 鉴权服务端部署说明（Win11 专业版 / 16G 内存）

## 一、准备
1. 装 Node.js LTS（本机已验证 v22 可用）：https://nodejs.org/zh-cn
2. 把 `server` 整个文件夹拷到服务器机器，如 `D:\hs-server\server`。

## 二、启动
```powershell
cd D:\hs-server\server
node server.js
```
- 默认监听 `0.0.0.0:8099`；改端口：`$env:PORT=9000; node server.js`（历史 8098 端口已弃用）
- 首次启动自动创建 `data/db.json`，并生成初始账号 **admin / admin123**（App 首次登录后请立即改密）。

## 三、开机自启与崩溃自愈（✅ 2026-10-10 起现行方案：NSSM 服务）

本机已把服务器包装为 Windows 服务 **HSAuthServer**（LocalSystem、自动启动、崩溃 5 秒自动拉起、日志轮转），实测 taskkill 杀进程后约 12 秒自动复活。旧方案（计划任务 HS-Auth-Server）已**禁用但保留**，可随时回滚。

```powershell
# 日常管理（均需管理员 PowerShell）
Restart-Service HSAuthServer          # 改了 server.js 后重启
Get-Service HSAuthServer              # 看状态
Get-Content D:\work_app\scan_station\server\data\logs\service.log -Tail 20   # 看日志

# 回滚到计划任务方案
nssm remove HSAuthServer confirm
Enable-ScheduledTask -TaskName "HS-Auth-Server"
Stop-Process -Name node -Force -ErrorAction SilentlyContinue; Start-ScheduledTask -TaskName "HS-Auth-Server"

# ⚠️ 注意：NSSM 本体在 C:\Users\<你>\AppData\Local\Microsoft\WinGet\Packages\NSSM.NSSM_...\win64\nssm.exe
#   不要 winget uninstall NSSM，否则服务失联（重启后起不来，需重装再注册）
```

当年注册命令（备查/换机重建用）：
```powershell
nssm install HSAuthServer "D:\nodejs\node.exe" "D:\work_app\scan_station\server\server.js"
nssm set HSAuthServer AppDirectory "D:\work_app\scan_station\server"
nssm set HSAuthServer AppStdout "D:\work_app\scan_station\server\data\logs\service.log"
nssm set HSAuthServer AppStderr "D:\work_app\scan_station\server\data\logs\service-error.log"
nssm set HSAuthServer AppRotateFiles 1; nssm set HSAuthServer AppRotateBytes 10485760
nssm set HSAuthServer AppExit 0 Restart; nssm set HSAuthServer AppRestartDelay 5000
nssm set HSAuthServer Start SERVICE_AUTO_START
```

<details><summary>旧方案：任务计划（已禁用，留档）</summary>

1. Win+R 输入 `taskschd.msc` → 创建基本任务：
   - 触发器：当用户登录时（选固定账号）
   - 操作：启动程序 → 程序 `node`，参数 `D:\hs-server\server\server.js`，起始于 `D:\hs-server\server`
2. 缺点：崩溃后不会自动拉起，机器重启依赖登录触发——这正是换 NSSM 的原因。
</details>

**存活探测**：浏览器打开 `http://服务器IP:8099/api/health` 返回 JSON（含 uptime/内存/各表计数）即正常。

## 四、防火墙放行（PDA 才能连上）
```powershell
netsh advfirewall firewall add rule name="HS-Auth-8099" dir=in action=allow protocol=TCP localport=8099
```

## 五、固定 IP
服务器在路由器/DHCP 上做 MAC 绑定固定内网 IP（如 172.25.1.99），App 登录页填 `http://172.25.1.99:8099`。

## 六、日常操作
- **建账号**：管理员登录 App → 设置 → 账号与权限 → 用户与功能管理 → 新建账号（选物料员/仓管员/管理员）。
- **停用/启用**：用户列表 → 停用（该用户在线会话立即被踢，App 端最迟 5 分钟心跳内弹出"账号已被停用"回登录页）。
- **功能开关**：管理页右上角"功能开关"，按角色勾选，保存后各端心跳刷新生效。
- **备份**：每天复制一次 `data\db.json`（计划任务或手动）。恢复=停服替换文件再启动。

## 七、安全边界（须知）
- 密码存储：scrypt+随机盐，数据库泄露不反推明文；但登录传输走 HTTP 内网明文，**仅限可信内网使用**。
- 鉴权判断全部在服务端，App 端隐藏入口只是体验；抓包伪造请求也会被 401/403 拒绝。
- 离线宽限：PDA 断网后凭上次校验 24 小时内仍可用（缓存角色），超时强制回登录页——停用对长期离网卡死有效。

## 八、接口清单（供后续领料单功能复用）
| 方法 | 路径 | 说明 |
|---|---|---|
| GET | /api/health | 存活探测（无鉴权：uptime/内存/各表计数） |
| POST | /api/login | 登录，返回 token+user+features |
| GET | /api/me | 心跳：当前身份+功能开关 |
| POST | /api/logout | 注销当前会话 |
| POST | /api/change_password | 改自己的密码 |
| GET/POST | /api/users | 管理员：用户列表/新建 |
| PATCH/DELETE | /api/users/{id} | 管理员：改（含停用）/删除 |
| GET/PATCH | /api/config | 管理员：功能开关读取/保存 |
